Slide 1 – Android Operating System
What is Android OS?
Android is an open-source operating system mainly designed for mobile and smart devices.

It is based on the Linux kernel and provides a platform where applications can run.

Simple example:
When you use WhatsApp, YouTube, Camera, or Google Maps on your phone, Android manages these applications and the phone's hardware.

For example:
YouTube app → Android OS → Phone hardware

You can say in presentation:
“Android is an open-source operating system based on the Linux kernel. It is mainly used in smartphones and other smart devices. Android manages both hardware and software resources and provides an environment for applications to run.”
