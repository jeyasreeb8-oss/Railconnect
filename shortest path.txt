Sure nanba 👍 Let’s learn Shortest Path Algorithms in a very simple, step-by-step way.

Shortest Path Algorithms
A shortest path algorithm finds the path with the minimum total cost/distance between vertices in a graph.

Common algorithms
Algorithm	Used for	Negative Edge?
BFS	Unweighted graph	Not applicable
Dijkstra's Algorithm	Weighted graph	❌ No
Bellman-Ford	Weighted graph	✅ Yes
Floyd-Warshall	All-pairs shortest path	✅ Yes
A*	Path finding using heuristic	Usually no
1. BFS – Shortest Path in Unweighted Graph
BFS is used when every edge has the same cost (usually 1).

Example
       B
      / \
     A   D
      \ /
       C
Find shortest path from A → D.

Possible paths:

A → B → D    = 2 edges
A → C → D    = 2 edges
So shortest distance = 2

Step-by-step
Step 1: Start at A.

Queue = [A]
Distance(A) = 0
Step 2: Visit A's neighbors B and C.

Distance(B) = 1
Distance(C) = 1

Queue = [B, C]
Step 3: Remove B and visit D.

Distance(D) = 2
Therefore:

A → B → D
is one shortest path.

Key idea
BFS explores vertices level by level, so it gives the shortest path in an unweighted graph.

2. Dijkstra's Algorithm ⭐
Dijkstra is one of the most important shortest-path algorithms.

It finds the shortest path from one source vertex to all other vertices.

Important condition
Dijkstra works when:

All edge weights are non-negative.

Example
       4
   A ------ B
   |        |
  1|        |2
   |        |
   C ------ D
       3
Also:

A → D = 10
Find shortest paths from A.

Step 1: Initialize distances
Starting vertex = A.

A = 0
B = ∞
C = ∞
D = ∞
∞ means we don't know the distance yet.

Step 2: Visit A
Edges from A:

A → B = 4
A → C = 1
Update:

A = 0
B = 4
C = 1
D = ∞
Choose the smallest unvisited distance:

C = 1
Step 3: Visit C
C has an edge to D:

C → D = 3
Distance through C:

A → C → D
= 1 + 3
= 4
So update:

D = 4
Now:

A = 0
B = 4
C = 1
D = 4
Choose C was already processed; next smallest is B or D, both 4.

Step 4: Visit B
B → D has weight 2.

Distance through B:

A → B → D
= 4 + 2
= 6
Current D = 4.

Since:

4 < 6
we don't update D.

Step 5: Final answer
A → A = 0
A → C = 1
A → B = 4
A → D = 4
Shortest path to D:

A → C → D
Total cost:

1 + 3 = 4
Dijkstra's main idea
Always select the unvisited vertex with the smallest known distance, then relax its neighboring edges.

3. Bellman-Ford Algorithm
Bellman-Ford is similar to Dijkstra but has one major advantage:

It can handle negative edge weights.
Example:

A ----4----> B
|            |
5           -3
|            |
↓            ↓
C <---------- 
Suppose:

A → B = 4
A → C = 5
B → C = -3
Find shortest path from A to C.

Step 1
Initially:

A = 0
B = ∞
C = ∞
Step 2: Relax A → B
B = 0 + 4
B = 4
Step 3: Relax A → C
C = 0 + 5
C = 5
Step 4: Relax B → C
C = B + (-3)
C = 4 - 3
C = 1
So:

A → B → C
has distance:

4 + (-3) = 1
which is shorter than direct:

A → C = 5
Important feature
Bellman-Ford can also detect a negative weight cycle.

4. Floyd-Warshall Algorithm ⭐
Floyd-Warshall finds shortest paths between every pair of vertices.

So it is called an:

All-Pairs Shortest Path Algorithm

Example
A → B = 5
A → C = 10
B → C = 3
Initially:

A → C = 10
But we can travel:

A → B → C
Cost:

5 + 3 = 8
Since:

8 < 10
we update:

A → C = 8
Basic formula
Floyd-Warshall uses:

D[i][j] = min(D[i][j],
              D[i][k] + D[k][j])
Meaning:

"Is going from i to j through k shorter?"

5. A* Algorithm
A* is commonly used in maps, games and navigation.

It uses two values:

f(n) = g(n) + h(n)
Where:

g(n) = actual cost from start to current node
h(n) = estimated cost from current node to destination
f(n) = total estimated cost
Example:

Start → A → B → Goal
A* chooses the node having the smallest estimated:

f(n)
This helps it find a path efficiently when a good heuristic is available.

🔥 Easy Comparison
Algorithm	Main Use	Negative Weight	Output
BFS	Unweighted graph	❌	Single source
Dijkstra	Positive weighted graph	❌	Single source
Bellman-Ford	Weighted graph	✅	Single source
Floyd-Warshall	All-pairs shortest path	✅	Every pair
A*	Maps/Games	Usually ❌	Source → Goal
🧠 Easy way to remember
No weights → BFS

Positive weights → Dijkstra

Negative weights → Bellman-Ford

Every vertex to every vertex → Floyd-Warshall

Maps / Games → A*

Sure nanba 👍 Here is a detailed but easy-to-study explanation of the three important shortest-path algorithms: Dijkstra, Bellman-Ford, and Floyd-Warshall. I’ll use small examples and show the calculations step by step.

1. Dijkstra's Algorithm
Definition
Dijkstra's Algorithm is a shortest-path algorithm used to find the minimum distance from one source vertex to all other vertices in a weighted graph.

It repeatedly selects the unvisited vertex with the smallest known distance and updates its neighboring vertices.

Important condition
Dijkstra's algorithm works only when all edge weights are non-negative.

Edge weights:
5, 2, 7, 1  → Valid
-3            → Not valid
Example
Consider this graph:

       4
   A ------ B
   |        |
  1|        |2
   |        |
   C ------ D
       3
Also assume:

A → D = 10
We need to find the shortest distance from A to all vertices.

Step 1: Initialize
Source = A.

Vertex	Distance	Visited
A	0	No
B	∞	No
C	∞	No
D	∞	No
The source has distance 0.

Step 2: Select A
A has the smallest distance:

A = 0
Check its neighbors.

For B:

A → B = 4

Distance(B) = 0 + 4 = 4
For C:

A → C = 1

Distance(C) = 0 + 1 = 1
For D:

A → D = 10

Distance(D) = 10
Now:

Vertex	Distance
A	0
B	4
C	1
D	10
Mark A as visited.

Step 3: Select C
The smallest unvisited distance is:

C = 1
C → D has weight 3.

Calculate:

Distance through C
= Distance(C) + Edge(C,D)
= 1 + 3
= 4
Current D = 10.

Since:

4 < 10
update D:

D = 4
Now:

Vertex	Distance
A	0
B	4
C	1
D	4
Step 4: Select B
B = 4.

B → D = 2.

Calculate:

A → B → D
= 4 + 2
= 6
Current D = 4.

Since:

4 < 6
we don't change D.

Step 5: Final result
A → A = 0
A → C = 1
A → B = 4
A → D = 4
Shortest path from A to D:

A → C → D
Total distance:

1 + 3 = 4
Basic steps of Dijkstra
1. Set source distance = 0.
2. Set all other distances = ∞.
3. Select the unvisited vertex with minimum distance.
4. Visit its neighboring vertices.
5. Update their distances if a shorter path is found.
6. Mark the vertex as visited.
7. Repeat until all vertices are processed.
Time Complexity
Using an adjacency matrix:

O(V²)
Using a priority queue/min-heap:

O((V + E) log V)
2. Bellman-Ford Algorithm
Definition
Bellman-Ford Algorithm finds the shortest distance from one source vertex to all other vertices.

Its major advantage is that it can handle negative edge weights.

It can also detect a negative-weight cycle.

Example
Consider:

A ----4----> B
|            |
5           -3
|            |
v            v
C <-----------
Edges:

A → B = 4
A → C = 5
B → C = -3
Source = A.

We want the shortest distance from A to C.

Step 1: Initialize
A = 0
B = ∞
C = ∞
Vertex	Distance
A	0
B	∞
C	∞
Step 2: Relax A → B
Edge weight = 4.

Distance(B)
= Distance(A) + 4
= 0 + 4
= 4
So:

B = 4
Step 3: Relax A → C
Edge weight = 5.

Distance(C)
= Distance(A) + 5
= 0 + 5
= 5
So:

C = 5
Current table:

Vertex	Distance
A	0
B	4
C	5
Step 4: Relax B → C
Edge weight = -3.

Distance(C)
= Distance(B) + (-3)
= 4 - 3
= 1
Current C = 5.

Since:

1 < 5
update:

C = 1
Therefore:

A → B → C
is the shortest path.

Total:

4 + (-3) = 1
Why does Bellman-Ford repeat?
Suppose there are V vertices.

Bellman-Ford relaxes all edges V−1 times.

Why?

A shortest simple path can contain at most:

V - 1 edges
So after V−1 rounds, all shortest paths should have been found if there is no negative cycle.

Negative Cycle Detection
This is an important feature of Bellman-Ford.

Suppose:

A → B = 2
B → C = -3
C → A = -2
Total cycle:

2 + (-3) + (-2)
= -3
Every time we go around the cycle, the distance becomes smaller.

Therefore, there is a:

Negative-weight cycle

After performing V−1 relaxations, Bellman-Ford performs one additional relaxation.

If the distance can still be reduced:

Negative-weight cycle exists
Bellman-Ford Steps
1. Set source distance = 0.
2. Set all other distances = ∞.
3. Repeat V−1 times:
      Relax every edge.
4. Perform one more relaxation.
5. If any distance changes,
      negative cycle exists.
6. Otherwise, shortest paths are obtained.
Time Complexity
O(VE)
where:

V = number of vertices
E = number of edges
Advantages
Handles negative edges.
Detects negative cycles.
Simple concept.
Disadvantage
It is slower than Dijkstra for graphs where all weights are non-negative.

3. Floyd-Warshall Algorithm
Definition
Floyd-Warshall Algorithm finds the shortest paths between every pair of vertices.

Therefore, it is called an:

All-Pairs Shortest Path Algorithm

Unlike Dijkstra and Bellman-Ford, which normally start from one source, Floyd-Warshall calculates:

A → B
A → C
A → D
B → A
B → C
B → D
C → A
...
Example
Consider:

A → B = 5
A → C = 10
B → C = 3
We want to find the shortest distance from A to C.

Initially:

A → C = 10
But we can travel through B:

A → B → C
Cost:

5 + 3 = 8
Since:

8 < 10
we update:

A → C = 8
Floyd-Warshall Uses a Matrix
Initial matrix:

From/To	A	B	C
A	0	5	10
B	∞	0	3
C	∞	∞	0
Where:

0 = distance from a vertex to itself
∞ = no direct path
Other values = edge weights
Step 1: Use A as intermediate vertex
Formula:

D[i][j] = min(D[i][j], D[i][A] + D[A][j])
For example, B → C through A:

B → A → C
= ∞ + 10
= ∞
No improvement.

Step 2: Use B as intermediate vertex
Now check A → C through B:

A → B → C
Calculate:

D[A][B] + D[B][C]

= 5 + 3

= 8
Current:

D[A][C] = 10
Therefore:

min(10, 8) = 8
Update:

A → C = 8
Final matrix:

From/To	A	B	C
A	0	5	8
B	∞	0	3
C	∞	∞	0
Floyd-Warshall Formula ⭐
The most important formula is:

D[i][j] = min(D[i][j],
              D[i][k] + D[k][j])
Meaning:

Check whether going from i to j through intermediate vertex k is shorter than the current path.

Floyd-Warshall Algorithm Steps
1. Create a distance matrix.
2. Put 0 for distance from a vertex to itself.
3. Put edge weights for directly connected vertices.
4. Put ∞ where there is no direct edge.
5. Select each vertex as an intermediate vertex.
6. Check every pair of vertices.
7. Update the distance if a shorter path is found.
8. After all vertices are considered, the matrix contains
   shortest distances between every pair.
Time Complexity
O(V³)
Space Complexity
O(V²)
🔥 Main Difference Between the Three
Feature	Dijkstra	Bellman-Ford	Floyd-Warshall
Shortest path	Single source → all	Single source → all	Every pair
Negative edges	❌ No	✅ Yes	✅ Yes
Negative cycle detection	❌	✅	✅
Approach	Greedy	Repeated relaxation	Dynamic Programming
Time complexity	O(V²) / O((V+E)logV)	O(VE)	O(V³)
Best suited for	Non-negative weighted graph	Negative edges	All-pairs shortest paths

Remember this:

Dijkstra
"Pick the nearest vertex."

Minimum distance
       ↓
Select vertex
       ↓
Relax neighbors
       ↓
Repeat
Bellman-Ford
"Relax every edge again and again."

All edges
   ↓
V-1 times
   ↓
Check again
   ↓
Negative cycle?
Floyd-Warshall
"Try every vertex as a middle point."

i → k → j

Is this shorter than

i → j ?
One-line definitions for exam
Dijkstra:

A greedy algorithm that finds the shortest paths from a single source to all other vertices in a graph with non-negative edge weights.

Bellman-Ford:

A shortest-path algorithm that finds single-source shortest paths and supports negative edge weights and negative-cycle detection.

Floyd-Warshall:

A dynamic programming algorithm that finds shortest paths between every pair of vertices in a weighted graph.
